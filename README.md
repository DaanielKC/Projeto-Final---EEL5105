# Projeto-Final---EEL5105
Esse é o Projeto Final da disciplina EEL5105 - Circuitos e Técnicas Digitais, realizado no meu 1º semestre da graduação em Ciência da Computação, na UFSC. Basicamente, o projeto consistia em implementar um jogo de adivinhar um código de 4 números diferentes, dentro de um limite de rodadas. Cada rodada, você tem 10 segundos para digitar o código e, após enviar, você recebe a quantidade de dígitos corretos na posição certa e quantos dígitos estão corretos, mas na posição errada. No final, você recebe uma pontuação baseada no número de rodadas que levou para você acertar, se acertar.

O projeto foi feito por mim, em colaboração com meu colega Pedro. Uma parte dos códigos foi entregue pronta pelo professor, e nossa tarefa era completar eles. Nós tivemos que completar o datapath, fazer todo o controle e criar boa parte dos componentes.

A linguagem utilizada nos códigos é VHDL.
